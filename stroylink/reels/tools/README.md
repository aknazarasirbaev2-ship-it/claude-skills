# Reels жазу құралы (overlay.py)

Дайын бейнеге (AI жасаған, 9:16) үлкен жазулар, бұрыштағы «Визуализация (ИИ)» белгісі және соңғы CTA-карточка қосады. Нәтиже: 1080x1920, H.264 + AAC, 30 fps, Instagram-ға дайын MP4. Қосымша генерация кредиті керек емес.

## 1. Бір рет дайындау

Компьютерде керек: **Python 3**, **ffmpeg** және **Pillow**.

1. ffmpeg бар-жоғын тексеру: терминалға `ffmpeg -version` деп жазыңыз. Жоқ болса, https://ffmpeg.org сайтынан орнатыңыз.
2. Pillow орнату: `pip install pillow`
3. Қаріп (шрифт) папкада дайын: `fonts/Inter-ExtraBold.otf`. Қосымша ештеңе орнатпаңыз.

## 2. Жұмыс істету

Терминалда осы папкаға (`tools`) кіріңіз де:

```
python3 overlay.py reel.mp4 plan.json reel_ru.mp4 --lang ru --label
```

- `reel.mp4`: сіздің бейне (кіріс)
- `plan.json`: жазулар жоспары (орысша), қазақша үшін `plan_kk.json`
- `reel_ru.mp4`: дайын нәтиже (өзге файл аты болуы керек)
- `--label`: бұрышқа «Визуализация (ИИ)» белгісін қояды (`--lang kk` болса «Визуализация (AI)»)

Қазақша нұсқа:

```
python3 overlay.py reel.mp4 plan_kk.json reel_kk.mp4 --lang kk --label
```

15 секундтық бейне шамамен 20 секундта өңделеді.

## 3. Жоспарды (plan.json) өзгерту

Файлды кез келген мәтін редакторымен ашыңыз. Әр жол: бір жазу.

```
{"start": 2.4, "end": 3.9, "text": "ЭЛЕКТРИКА И ТРУБЫ", "position": "bottom", "style": "step"}
```

- `start`, `end`: жазу қай секундта шығып, қай секундта кетеді
- `text`: мәтін (өзі БАС ӘРІПКЕ айналады; кішкентай қалдыру үшін `"upper": false`)
- `position`: `top` (жоғары), `center` (орта), `bottom` (төмен)
- `style`: `step` (қара жәшік, ақ мәтін), `hook` (үлкенірек, ашылу жазуы), `accent` (сары жәшік, «ГОТОВО» үшін), `plain` (жәшіксіз, контур)
- бір орында екі жазудың уақыты қиылыспауы керек (құрал ескертеді)

Соңғы карточка файлдың соңында:

```
"end_card": {"text": "НАПИШИТЕ «РЕМОНТ» В DIRECT", "seconds": 2.0}
```

`seconds`: карточка соңғы неше секундта тұрады (бейне ұзындығы өзгермейді).

Мәтін қорғалған аймақта тұрады: жоғарыдан 220 px және төменнен 420 px бос қалады (Instagram интерфейсі жабатын жер). Ұзын мәтін автоматты түрде жолға бөлінеді немесе кішірейеді.

## 4. Тексеру

Дайын файлды ашып, мына жерлерді қараңыз: мәтін оқылады ма, әріптер (Ә, Ғ, Қ, Ң, Ө, Ұ, Ү, Һ, І) дұрыс па, жазулар ақырын пайда болып жоғала ма, соңғы карточка шықты ма.

## 5. Мәселе болса

| Хабар | Не істеу |
|---|---|
| `ffmpeg not found` | ffmpeg орнатыңыз (1-қадам) |
| `Pillow is not installed` | `pip install pillow` |
| `Input video not found` | файл аты мен жолын тексеріңіз |
| `overlay #N: ...` | plan.json-дағы N-ші жазудың `start`/`end`/`position` өрісін түзетіңіз |
| `WARNING: ... no glyphs` | қаріпте жоқ таңба бар; басқа таңбамен ауыстырыңыз |

## Шектеулер

- Кіріс 9:16 емес болса, шеттері қиылып 1080x1920 толтырылады.
