# StroyLink — сайт для Google (статический, без сервера)

Сайт: подбор компании для ремонта квартиры в Алматы. Заявка с сайта уходит в WhatsApp (сервер и база не нужны).

## Страницы
| Путь | Для каких запросов в Google |
|---|---|
| `/` | ремонт квартир алматы, найти компанию для ремонта |
| `/kz/` | пәтер жөндеу алматы (қазақша) |
| `/remont-v-novostrojke/` | ремонт в новостройке алматы, черновая отделка |
| `/stoimost-remonta/` | стоимость / сколько стоит ремонт квартиры в алматы |
| `/kak-vybrat-podryadchika/` | как выбрать компанию для ремонта, договор на ремонт |
| `/privacy/` | политика конфиденциальности (обязательно для формы) |

## Перед публикацией (обязательно)
1. **Номер WhatsApp**: в `assets/main.js` замените `WA_NUMBER: "77000000000"` на свой номер (только цифры, напр. `77011234567`).
2. **Домен**: замените `SITE-DOMAIN.kz` во всех файлах на ваш адрес:
   ```bash
   grep -rl 'SITE-DOMAIN.kz' . | xargs sed -i 's#SITE-DOMAIN.kz#ваш-домен.kz#g'
   ```
   Бесплатный вариант без домена: `имя.pages.dev` (Cloudflare Pages) или `имя.netlify.app`.
3. **Политика конфиденциальности**: заполните `[ФИО / ИП ...]` в `privacy/index.html` и покажите юристу.
4. (Необязательно) **PostHog**: впишите ключ `phc_...` в `POSTHOG_KEY` в `assets/main.js` — сайт будет отправлять события `site_quiz_started`, `site_lead_submitted`, `site_whatsapp_click`.

## Бесплатный хостинг (Cloudflare Pages или Netlify)
- **Netlify Drop**: откройте app.netlify.com/drop и перетащите папку `site` — сайт готов за минуту.
- **Cloudflare Pages**: Create project → Upload assets → папка `site`.
- Домен `.kz` стоит денег (≈ несколько тысяч ₸ в год); для старта хватит бесплатного поддомена.

## Чтобы Google нашёл сайт
1. **Google Search Console** (search.google.com/search-console): добавить сайт → подтвердить → «Файлы Sitemap» → `sitemap.xml` → «Проверка URL» → «Запросить индексирование» для каждой страницы.
2. **Профиль компании в Google (Google Business Profile)**: тип «Услуги на выезде / без адреса для посетителей», зона обслуживания — Алматы. Это даёт показ на Google Картах. Указывайте честную категорию (консультации/подбор), не «ремонтная компания».
3. Ссылку на сайт добавить: в био Instagram @stroy.ling, в WhatsApp-профиль, в 2GIS (бесплатная карточка).
4. Раз в 1–2 недели — новая полезная статья (например «Приёмка квартиры у застройщика: чек-лист», «Ремонт санузла: этапы»). Google лучше ранжирует сайты, которые обновляются.

> Важно: первые позиции в Google без рекламы появляются не сразу (обычно недели–месяцы). Пока сайт индексируется, основной поток — из плана `06-client-acquisition-no-budget.md`; сайт нужен, чтобы ссылку можно было дать в группах и Instagram, и человек сам оставил заявку.
