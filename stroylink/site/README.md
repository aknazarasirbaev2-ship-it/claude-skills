Статикалық сайт, сервер керек емес. Өтінім WhatsApp-қа (+7 747 202 39 69) кетеді, көшірмесі stroyling12@gmail.com поштасына келеді.

| `/privacy/` | `/ru/privacy/` | құпиялылық саясаты |

## Басты беттегі эффектілер
- «Қара әрлеу → жөндеуден кейін» сырғымалы слайдер (тінтуірмен/саусақпен жылжытылады, ашылғанда өзі анимацияланады)
- Аудандардың жылжымалы жолағы, scroll-ға бекітілген горизонталь «өтінім жолы» (компьютерде), саусақпен сырғытылатын карточкалар (телефонда)
- Жөндеу кезеңдері: айналдырған сайын сурет ауысады
- «7 сұрақ / 6 қауіп белгісі» қойындылары, анимациялы FAQ, сурет галереясы, «магнитті» батырмалар, курсор
- Анимация кітапханасы: GSAP 3.12.5 (cdnjs). Жүктелмесе, сайт анимациясыз жұмыс істейді.

## Жариялау алдында
1. **Домен**: `SITE-DOMAIN.kz` деген жерді нақты доменге ауыстырыңыз:
   ```bash
   grep -rl 'SITE-DOMAIN.kz' . | xargs sed -i 's#SITE-DOMAIN.kz#ваш-домен.kz#g'
   ```
2. **Email-ды іске қосу (бір рет)**: сайттағы бірінші өтінімнен кейін stroyling12@gmail.com-ға FormSubmit-тен «Activate Form» хаты келеді — сілтемесін басыңыз. Содан кейін әр өтінімнің көшірмесі поштаға келеді.
3. **Құпиялылық саясаты**: `[ТАӘ / ЖК]`, `[БСН/ЖСН]` орындарын толтырып, заңгерге көрсетіңіз.
4. Қазақша мәтінді қазақ тілін жақсы білетін адамға бір рет оқытып шығыңыз.

## Тегін хостинг
- **Netlify Drop**: app.netlify.com/drop — `site` папкасын сүйреп тастаңыз.
- **Cloudflare Pages**: Create project → Upload assets → `site` папкасы.

## Google-да шығу
1. **Google Search Console**: сайтты қосу → `sitemap.xml` жіберу → әр бетке «Индекстеуді сұрау».
2. **Google Business Profile**: «қызмет көрсету аймағы — Алматы», мекенжайсыз. Санат — кеңес беру/таңдауға көмек (жөндеу компаниясы емес).
3. Сілтемені Instagram био, WhatsApp профилі, 2GIS-ке қойыңыз.

## Суреттер
Интерьер суреттері — Unsplash (тегін лицензия, коммерцияға рұқсат). Сайтта «мысал ретінде» деп белгіленген. Өз серіктестеріңіздің нақты нысандарының суреті болғанда, `assets/img/` ішіндегі файлдарды ауыстырыңыз.
